What the web app does

1

Patient intake form

Page 1

  • Patient enters name, phone, specialty, preferred date/time
  • Submits form → backend calls Bolna API to trigger outbound call
  • Patient's phone rings — Asha confirms the booking over call
2

Admin dashboard

Page 2

  • Live table of all appointments: name, status, call outcome
  • Status updates via Bolna webhook (booked / no-answer / escalated)
  • One-click "Send reminder" triggers Asha reminder call
3

Call transcript viewer

Page 3

  • Click any appointment → see full call transcript
  • Shows what Asha said, what patient said, outcome
  • Demonstrates webhook + transcript API integration
4

Analytics strip

Page 2 footer

  • Total calls made, confirmed, escalated, no-answer
  • No-show reduction % (simulated)
  • Cost saved vs human agent (calculated live)

Recommended stack

React + Vite (frontend) Node + Express (backend) SQLite or in-memory store Bolna webhook endpoint Deploy: Vercel + Railway GitHub repo

Key Bolna API calls you'll make

Webhook — Bolna POSTs this to your backend after call ends POST https://your-app.com/webhook/bolna { call_id: "abc123", status: "completed", transcript: [...], duration: 119, outcome: "booked" } // 3.
